# エスケープシーケンス


| エスケープシーケンス    | 説明                                                                      |
| ------------- | ----------------------------------------------------------------------- |
| **\a**        | ベル (警告)                                                                 |
| **\b**        | バックスペース                                                                 |
| **\f**        | フォーム フィード                                                               |
| **\n**        | 改行                                                                      |
| **\r**        | キャリッジ リターン                                                              |
| **\t**        | 水平タブ                                                                    |
| **\v**        | 垂直タブ                                                                    |
| $             | 単一引用符                                                                   |
| $             | 二重引用符                                                                   |
| **\\\\**      | \記号                                                                     |
| $             | リテラル疑問符                                                                 |
| **\\** _ooo_  | 8 進表記の ASCII 文字                                                         |
| **\x** _hh_   | 16 進表記の ASCII 文字                                                        |
| **\x** _hhhh_ | このエスケープ シーケンスがワイド文字定数または Unicode 文字列リテラルで使用されている場合は、16 進表記の Unicode 文字。 |
