# エスケープシーケンス


| エスケープシーケンス    | 説明                  |
| ------------- | ------------------- |
| **\a**        | ベル (警告)             |
| **\b**        | バックスペース             |
| **\f**        | フォーム フィード           |
| **\n**        | 改行                  |
| **\r**        | キャリッジ リターン          |
| **\t**        | 水平タブ                |
| **\v**        | 垂直タブ                |
| **\\\\**      | \記号                 |
| **\x** _hh_   | 16 進表記の ASCII 文字    |
| **\u** _hhhh_ | 16 進表記の Unicode 文字。 |
