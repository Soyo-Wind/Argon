# bool

**型.bool**

bool 型は、Bool値 (true(1) または false(0) のいずれか) を表す.
`bool` 型の値を使って論理演算を実行するには、[ブール論理演算子](ブール論理演算子.md)を使用します。 `bool` 型は、[比較](比較演算子.md)および[等値](./../演算子/等値演算子.md)演算子の結果の型です。 `bool` 式は、[if](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/statements/selection-statements#the-if-statement)および [for](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/statements/iteration-statements#the-for-statement) 関数 で制御条件式にすることができます。

`bool` 型の既定値は `false` です。
