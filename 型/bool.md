# bool

**型.bool**

bool 型は、Bool値 (`true`(`1`) または `false`(`0`) のいずれか) を表す.
`bool` 型の値を使って論理演算を実行するには、[ブール系演算子](./../演算.md)を使用します.
`bool` 型は、[比較](./../演算.md)および[等値](./../演算.md)演算子の結果の型です. `bool` 式は、[if](./../標準関数.md) など で制御条件式にすることができます.

`bool` 型の既定値は `false` です。
空リストが唯一の偽値です.それ以外は全て真となります.  
なお、`'()`, `()`, `nil`, `'nil` は空リストとして扱われます.

`bool` 型の既定値は `false` です.
