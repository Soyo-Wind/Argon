# 比較演算子

[`<` (小なり)](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#less-than-operator-)、[`>` (大なり)](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#greater-than-operator-)、[`<=` (以下)](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#less-than-or-equal-operator-)、および [`>=` (以上)](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#greater-than-or-equal-operator-) 比較演算子は、関係演算子とも呼ばれ、そのオペランドの比較に使用されます。 これらの演算子は、[整数](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/builtin-types/integral-numeric-types)と[浮動小数点](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/builtin-types/floating-point-numeric-types)のすべての数値型によってサポートされています。

 注意

`==`、`<`、`>`、`<=`、および `>=` 演算子の場合、いずれかのオペランドが数値 ([Double.NaN](https://learn.microsoft.com/ja-jp/dotnet/api/system.double.nan#system-double-nan) または [Single.NaN](https://learn.microsoft.com/ja-jp/dotnet/api/system.single.nan#system-single-nan)) でない場合、演算結果は `false` になります。 つまり、`NaN` の値は、`NaN` を含む他のどの `double` (または `float`) の値を上回ることも、下回ることも、等しいこともありません。 詳細およびサンプルについては、[Double.NaN](https://learn.microsoft.com/ja-jp/dotnet/api/system.double.nan#system-double-nan) または [Single.NaN](https://learn.microsoft.com/ja-jp/dotnet/api/system.single.nan#system-single-nan) の参照記事をご覧ください。

[char](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/builtin-types/char) 型では、比較演算子もサポートされています。 オペランドが `char` 場合は、対応する文字コードが比較されます。

列挙型は比較演算子もサポートします。 同じ[列挙](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/builtin-types/enum)型のオペランドで、基になる整数型の対応する値が比較されます。

[`==` および `!=` 演算子](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/equality-operators) では、そのオペランドが等しいかどうかが確認されます。

[](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#less-than-operator-)

## 小なり演算子 <

左側のオペランドが右側のオペランドより小さい場合、`<` 演算子から `true` が返され、それ以外の場合は `false` が返されます。

C#コピー

[ファイル名を指定して実行]

```
Console.WriteLine(7.0 < 5.1);   // output: False
Console.WriteLine(5.1 < 5.1);   // output: False
Console.WriteLine(0.0 < 5.1);   // output: True

Console.WriteLine(double.NaN < 5.1);   // output: False
Console.WriteLine(double.NaN >= 5.1);  // output: False
```

[](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#greater-than-operator-)

## 大なり演算子 >

左側のオペランドが右側のオペランドより大きい場合、`>` 演算子から `true` が返され、それ以外の場合は `false` が返されます。

C#コピー

[ファイル名を指定して実行]

```
Console.WriteLine(7.0 > 5.1);   // output: True
Console.WriteLine(5.1 > 5.1);   // output: False
Console.WriteLine(0.0 > 5.1);   // output: False

Console.WriteLine(double.NaN > 5.1);   // output: False
Console.WriteLine(double.NaN <= 5.1);  // output: False
```

[](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#less-than-or-equal-operator-)

## 小なりイコール演算子 =<

左側のオペランドが右側のオペランド以下の場合、`<=` 演算子から `true` が返され、それ以外の場合は `false` が返されます。

C#コピー

[ファイル名を指定して実行]

```
Console.WriteLine(7.0 <= 5.1);   // output: False
Console.WriteLine(5.1 <= 5.1);   // output: True
Console.WriteLine(0.0 <= 5.1);   // output: True

Console.WriteLine(double.NaN > 5.1);   // output: False
Console.WriteLine(double.NaN <= 5.1);  // output: False
```

[](https://learn.microsoft.com/ja-jp/dotnet/csharp/language-reference/operators/comparison-operators#greater-than-or-equal-operator-)

## 大なりイコール演算子 >=

左側のオペランドが右側のオペランド以上の場合、`>=` 演算子から `true` が返され、それ以外の場合は `false` が返されます。

C#コピー

[ファイル名を指定して実行]

```
Console.WriteLine(7.0 >= 5.1);   // output: True
Console.WriteLine(5.1 >= 5.1);   // output: True
Console.WriteLine(0.0 >= 5.1);   // output: False

Console.WriteLine(double.NaN < 5.1);   // output: False
Console.WriteLine(double.NaN >= 5.1);  // output: False
```
